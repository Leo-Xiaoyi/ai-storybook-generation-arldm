# Release Safety

This repository is prepared as a public GitHub portfolio artifact.

## Included

- final thesis-oriented ARLDM adaptation code
- Oxford dataset loader
- Oxford preprocessing and HDF5 conversion scripts
- model configuration
- small representative five-frame generated output sequence
- documentation explaining scope, data preparation, model pipeline, and
  portfolio positioning

## Excluded

- raw storybook PDFs
- extracted images and captions
- full HDF5 datasets
- LLaMA2 model files
- Stable Diffusion model cache
- BLIP weights and other checkpoints
- training logs and generated experiment archives
- personal server notes, node names, and absolute cluster paths
- school administrative documents
- unrelated study materials

## Why Not Upload Everything

Uploading an entire research working folder is not professional for a public
portfolio. It usually exposes irrelevant files, private paths, heavyweight
artifacts, duplicate experiments, and assets that other people cannot legally or
practically use.

The goal of this repository is to show the final implementation path and the
project story clearly: what problem the project solved, what code was adapted,
what data pipeline was built, what was evaluated, and what can be discussed in
an interview.
